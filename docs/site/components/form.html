A sheet with input fields: a tap focuses a field, the screen's keyboard dock opens and types into it, Enter submits.

A sheet is an instance of the library's #sheet with the app's content component swapped into its slot: see #sheet.

The fields are slots of #input-field inside the sheet's content component (#wifi/password); the form is code.

form in the app for AI: docs/ai/form.md

gesture→actions→state→presenter→UI model→harry draws

See #sheet.

Form::new(layout, fields) wraps a Sheet and the fields' InputFields, in the order given. on(node, gesture, now, keyboard) routes a tap to the field by its node name and the keyboard's outcome to the focused field; it answers Focused(i), Edited(i), Submitted(i). The keyboard dock follows the focus: state.osk.follow(form.focused().is_some()) after every action.

pub struct Form

A sheet with input fields.

pub fn new(layout: Layout, fields: impl IntoIterator<Item = (impl Into<String>, InputField)>) -> Self

A closed form in a sheet of this layout, with these fields, each named by its slot on the screen.

pub fn open(&mut self)

Opens it, nothing in focus; the change animates with the open transition.

pub fn close(&mut self)

Closes it and takes the focus away (the keyboard closes with it); the change animates with the close transition.

pub fn is_open(&self) -> bool

Whether the sheet is open.

pub fn clear(&mut self)

Empties the fields (texts and errors); placeholders and helpers stay.

pub fn field(&self, index: usize) -> &InputField

A field, by its index in new.

pub fn field_mut(&mut self, index: usize) -> &mut InputField

A field to change, by its index in new.

pub fn focused(&self) -> Option<usize>

The field with the focus; the keyboard dock follows it.

pub fn focus(&mut self, index: usize, now: Instant)

Gives a field the focus; a disabled field does not take it.

pub fn blur(&mut self)

Takes the focus away from every field.

pub fn on(&mut self, node: &str, gesture: Gesture, now: Instant, keyboard: &mut Keyboard) -> Option<FormEvent>

Applies a gesture from a node of the form: a tap on a field moves the focus there, a key (of the screen's keyboard) goes to the field in focus. None for a node that is not a field or a key, while a key is held, for Shift / mode, and for a key without a field in focus.

pub enum FormEvent

What the form reports; the index is the field's, in the order given to new.

FocusedA tap gave a field the focus (the keyboard opens).
EditedA key changed a field's text.
SubmittedDone on the keyboard: the field's text is submitted.

  1. A property, a value or a transition: components.json; the order of props is the order of the variant name.
  2. The drawing: the component set <app>-sheet in the Figma library, every variant; the layers the code sets keep their names <app>-sheet/<part>, nothing hidden.
  3. The behaviour: the Rust module (Form; variant() produces the set's variant string); the parts: the harry binding.
  4. Fetch the design into the app and run everyware_ui_test: it fails when a variant or a part the code uses is missing in the design.
Traps
  • A dialog with a form moves above the keyboard dock (the free height); a side panel does not.
  • The field's text is the form's, not the keyboard's: the keyboard only reports outcomes.
