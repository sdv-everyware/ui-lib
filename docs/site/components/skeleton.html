Put it on a screen

  1. Assets → the library → drag #skeleton onto the screen and pick any variant (the app sets the real one).
  2. Wrap it in a frame (Ctrl/Cmd + Alt + G) of the same size and name the frame SLOT: that name is the contract with the app.
  3. Texts in the preview are placeholders: the app writes into the parts named #skeleton/…. Nothing hidden.

The finger is on the node named SLOT: harry hit-tests the drawn tree and hands the app Gesture::Down, moves, Gesture::Up with that name.

actions.rs: nothing: display only

This component shows data; it takes no gestures.
once per app: the listener that turns harry's input into an action (ui_event_listener.rs) 
impl UiEventListener for UiListener {
    fn handle_event(&mut self, event: UserInputEvent) -> HandleEventStatus {
        // everyware_ui::Input groups harry's touch events into Gesture::Down / Move / Up per node
        for (node, gesture) in self.input.feed(&event) {
            let _ = self.actions.send(Actions::CustomAction(HomeAction::Gesture(node, gesture)));
        }
        HandleEventStatus::Consumed
    }
}

state.rs: the component lives in the app's state

One value per place on the screen; it holds what is pressed, chosen, typed. The app owns it, so it survives between frames and the presenter can read it.

pub struct State {
    pub skeleton: Skeleton,
}

presenter.rs: state → UI model

After every action the presenter writes the component into its slot: variant, texts, opacities, the transition of the last change.
model.skeleton = slot("SLOT", &state.skeleton);

One field per node in everyware_ui::ui_model! { ... }; the SlotCustomizer turns it into harry's customizations.

Rust API

core/src/skeleton.rs

pub struct Skeleton

A skeleton placeholder: its shape, and since when it is loading (None: still).

pub fn new(kind: SkeletonKind, size: SkeletonSize) -> Self

A still skeleton of kind and size.

pub fn start(&mut self, now: Instant)

Loading from now: the band starts sweeping (a skeleton already loading keeps its phase, so a second call does not make it jump).

pub fn stop(&mut self)

Loaded (or given up): the band stops.

pub fn is_loading(&self) -> bool

Whether the band sweeps.

pub fn period() -> Duration

The length of one pass of the band (components.json, sweep).

pub fn sweep_at(&self, now: Instant) -> Option<f32>

Where the band is at now, 0..100 across the skeleton; None when it stands still.

harry bindingvendor/sdv-everyware/ui-lib/harry/src/slot.rs:753 the parts of the clone the code sets
  1. A property, a value or a transition: components.json; the order of props is the order of the variant name.
  2. The drawing: the component set #skeleton in the Figma library, every variant; the layers the code sets keep their names #skeleton/<part>, nothing hidden.
  3. The behaviour: the Rust module (Skeleton; variant() produces the set's variant string); the parts: the harry binding.
  4. Fetch the design into the app and run everyware_ui_test: it fails when a variant or a part the code uses is missing in the design.
