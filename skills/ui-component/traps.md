# Traps (each one found on the RB3 / in Figma, 2026-11-03 and 11-05)

| Symptom | Cause | Fix |
|---------|-------|-----|
| Figma: "This layer has an invalid name. Make sure that all variant names are of the form Prop=Value" | current Figma reads variant values from `componentPropDefs` (set) and `variantPropSpecs` (variant), not from the names | `componentSet()` in fig-helpers.js writes both; keep using it |
| after import the instances are called `#button`, `#toggle` instead of `#wifi/connect` | the node name of an instance is replaced on import; Figma keeps an instance's own name as a symbol override on the variant root | `instance()` writes `{ name, guidPath: [variant guid] }`; check in Layers after every import |
| fetch: `HTTP 404 /v1/components/<key>`, variants missing in the .dcf | the fetch resolves node names only one level below the pages; sets inside a frame on another page are taken for library components | the fetch also gets `Library` (default `DCF_NODES`); keep the sets inside `Library` |
| `fetch-dcf.sh` fetched the old file | every import is a new document with a new key | pass the new key, then write it to `scripts/figma-key` |
| a pressed button loses the text set from code | a variant swap rebuilds the instance from the new variant; renamed inner layers are lost, text overrides are kept | static labels as text overrides in Figma (`labelled()` in keyboard-patch.js); dynamic texts on layers named in the component |
| two instances of one component move or show the same | inner layers have the component's names in every instance; harry looks customizations up by node name only | put each in a slot (slot.rs): a list item has its own customizations for its subtree |
| toggle switches in steps, not smoothly | a variant change rebuilds the tree and lays out the screen (~50 ms a frame on the RB3) | the value is a meter / opacity (display-only), the variant only the state |
| a marker (toggle thumb) starts in the wrong place and moves past the end | harry draws a horizontal progress marker at node x + startX..endX (it cancels only the y of a vertical one, generation.rs) | marker node at x = 0 of its parent; startX..endX its travel |
| a marker's value changes (a slider's thumb) but nothing moves on the screen | harry moves a progress marker's own shape (rect, rounded rect, vector rect; generation.rs `override_rect`), not the children of a frame | the marker is the shape itself (a rounded rect with the meter); a pressed halo is a second marker with the same travel |
| `Clone is not implemented for <X>Customizer` | the derive makes `UiModelCustomizers` Clone and Debug | `#[derive(Clone, Debug, Default)]` on every customizer |
| a moving part inside a harry list item jumps instead of moving | `DefaultListCustomizer` returns Finished and the list is cloned on every apply, so state in an item is lost | `SlotCustomizer` keeps the Follow state and returns NextFrame while moving |
| a text in a slot wraps one character per line | harry's layout measured it with the design's text, not the item's (the measure callback held the base TextHelper) | harry patch 0005; a hug text (`textAutoResize: 'WIDTH_AND_HEIGHT'`) in an auto-layout row then follows its content |
| a part at opacity 0 in the design (focus ring, caret) never shows, a fade only switches | harry's animation pass applied only the global customizations, the drawn style kept the design's opacity | harry patch 0005 |
| a layer the code writes to is missing after import | Figma may drop an empty text node | preview text of at least a space (`#input-field/text`) |
| `component set #x not in the .dcf` in everyware_ui_test | the set is not used on a screen, so it is only inside the `Library` frame | the test searches the whole tree; if it still fails, the fetch did not get `Library` |
| `visibility: ... is not allowed` for a filegroup outside //vendor | Soong lets packages outside //vendor open to `//vendor:__subpackages__` only | use that (smarthome-app's `smarthome_app_dcf`) |
| no animation from Figma prototype | harry does not read prototype transitions (`squoosh/src/view.rs`, TODO b/431281126) | transitions come from components.json via `AnimationOverride` |
| `proc-macro derive panicked: Unsupported field type ... Type::Group` | a `macro_rules!` `$ty:ty` reaches the derive wrapped in an invisible group | take the type as `$ty:tt` (ui_model! in the app) |
| `Command depended on ".../components.json", which was not listed as an input` | `include_str!` reads a file Soong does not know | `crate_root` + the json in `srcs` (rust modules have no `compile_data`) |
| `cannot satisfy dependencies so bssl_sys only shows up once` | two TLS stacks (rustls and SDV's openssl) in one .so | not a UI issue, but: one TLS stack per process (smarthome docs, 7-extensions) |
| `"src/x.rs", needed by ..., missing and no known rule to make it` | a source file was deleted while ninja still had it in the old depfile | recreate it empty, build once, delete it |
| a tap does not reach the app | the field lacks `interactive`, or the node is hidden in Figma | `interactive` on the instance node; nothing hidden in the generators |
| translucent card shows the dashboard through the text | paint opacity is dropped on import; node opacity doubled | opaque fills in the library |
| an instance of a sheet set lands in the root column's flow (a strip at the bottom, the open sheet drawn below the screen, every tap after "open" swallowed by the sheet) | `stackPositioning: ABSOLUTE` is kept by Figma's import on a FRAME and dropped on an INSTANCE; the fetch then has `layoutPositioning: AUTO` | the instance inside a plain frame with `stackPositioning: 'ABSOLUTE'` (keyboard-patch.js `Wi-Fi sheet layer`, `Keyboard layer`); the frame is positioned by constraints |
| a variant switch of a sheet jumps, nothing slides or fades | harry animates each node with its own `AnimationOverride` or the reducer's default spec; a parent's override is not inherited (`squoosh/src/view.rs` animate_changes, the override is inherited only for the fade-in of new nodes) | one `AnimationOverride` field per moving part (`#wifi/scrim`, `#wifi/card`, `#osk/keys`), set to the instance's transition in the presenter |
| the sheet is "open" in the state but nothing shows, and every tap after that is swallowed | the sheet's nodes were laid out off screen (see the absolute trap); the state machine does not know | fix the layout; the app's guard `if form.overlay.open => on_sheet` is correct |
| the glyph in every row is the same although the code sets a variant per row | harry does not swap a variant inside a list item (`overrides.rs` reads the global customizations only) | a glyph stack per icon slot, one lit by opacity per item (`#list-item/leading/<glyph>`) |
| the whole scrollbar (track and thumb) scrolls away with the content | the scrollbar sat in the same slot mechanism as the rows and got the scroll subtracted | the customizer leaves a `thumb` item in place and moves only the rows |
| a tap on a row does nothing while a topic feeds the list | the rows were replaced between the down and the up; the new row was never pressed | `ListView::set_rows` carries pressed/selected over by title; the app skips an unchanged list; the bundle publishes only changes |
| a drag that starts in the gap between rows is dropped | the touch starts on no node (RAW), the tracker ignores a start without a node | the list slot itself `interactive`; `ListView::on(None, ...)` takes the drag |
| synthetic taps hit the power key | `/dev/input/event0` changed after a reboot | find the touch device by `ABS_MT_POSITION_X` (`tap.sh`) |
| a dropdown in a row sits half above the screen after a regenerate | the component is as tall as its open list (204), its slot takes that height and the row centres it | the slot keeps the closed pill's height (48), counter-align MIN, the list hangs below (frameMaskDisabled); `dashboard-patch.js` DROPDOWN_PILL_H |
| a picture set on a part (`set_image`) does not show, the placeholder stays | harry draws an image customization on a plain rectangle only (`pre_renderer/generation.rs`, `Shape::Rect`); a node with rounded corners is a `RoundRect` and the picture is skipped without a warning | the part is a frame without corners (`#list-item/image`), the rounding is a clipping frame around it |
| a long text runs into the line below | a text box in Figma has a fixed height but harry wraps the text to as many lines as it needs | `maxLines` and `textTruncation: 'ENDING'` on the text (harry passes them to Impeller: max lines, ellipsis) |
